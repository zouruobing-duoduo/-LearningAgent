# 同步经验文档到飞书知识库

## 执行步骤

### Step 1: 检查是否有新经验需要补充
在同步之前，先回顾当前会话中是否产生了新的经验教训：
1. 回顾本轮对话中的 bug 修复、架构决策、踩坑记录
2. 对比 `docs/experience.md` 现有内容，识别缺失的条目
3. 如果有新经验，先更新 `docs/experience.md`，按现有格式追加到对应章节：
   - 专家经验 → 第一章
   - 常见陷阱 → 第二章
   - 项目核心决策 → 第三章
4. 同时调用 `update_memory` 将新经验存入记忆系统（双保险）

### Step 2: 运行同步脚本
```powershell
cd e:\GitCode\LearningAgent; py -3 sync_to_wiki.py
```

### Step 3: 验证输出
检查脚本输出，确认：
- `找到已有文档` 或 `创建文档成功` — 文档定位/创建成功
- `文档已成功同步到飞书知识库` — 内容写入成功

### Step 4: 处理异常
- 权限不足：提示用户在飞书开放平台开通 `docx:document` 权限
- 知识空间不存在：提示用户先在飞书中创建知识库
- 写入失败：检查 block 格式是否有变更

## 关键信息
- 知识空间名称：苏格拉底
- 文档标题：苏格拉底学习Agent - 开发经验沉淀
- 脚本已内置查重逻辑，重复运行不会创建多份文档
- 源文件路径：`docs/experience.md`
